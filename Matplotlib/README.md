# 📊 Matplotlib Practice

A collection of my **Matplotlib practice notebooks**, covering different types of plots, chart customization, subplots, and data visualization techniques.

This repository documents my learning journey in **Data Visualization with Python** and serves as a reference for the concepts and techniques I have practiced.

---

## 🚀 What I Practiced

### 📈 Basic & Statistical Plots

* **Line Plot** — trends and continuous data
* **Bar Chart** — comparison between categories
* **Histogram** — distribution of numerical data
* **Pie Chart** — proportions and percentages
* **Scatter Plot** — relationships between two variables
* **Box Plot** — distribution, median, quartiles, and outliers
* **Stem Plot** — displaying data values using stems and markers
* **Step Plot** — showing discrete changes over time
* **Area Plot** — visualizing trends and cumulative values

### 🎨 Advanced Visualization Techniques

* **Subplots** — creating multiple plots in a single figure
* Figure sizing and layout
* Titles and axis labels
* Legends
* Grid customization
* Markers
* Line styles
* Colors and transparency
* Annotations
* Highlighting important data points
* `where` parameter in step plots
* Combining multiple Matplotlib functions
* Creating dashboard-style visualizations
